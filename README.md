# NexusCRM 🚀

NexusCRM is a modern, high-performance Customer Relationship Management software built with **React**, **TypeScript**, and **Vite**. It features a "dekhte bhalo" (beautiful) interface with glassmorphism, smooth animations, and a premium design system.

## ✨ Features

- **Dynamic Dashboard**: Overview of key performance indicators (KPIs) and sales targets.
- **Customer Management**: Clean and efficient data table for tracking leads and active clients.
- **Pipeline Tracking**: Visual representation of deals and success rates.
- **Glassmorphism Design**: Modern UI with backdrop blurs and subtle gradients.
- **Responsive Layout**: Optimized for various screen sizes.

## 🛠️ Tech Stack

- **Frontend**: React 18
- **Language**: TypeScript
- **Styling**: Vanilla CSS (Custom Design System)
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **Build Tool**: Vite

## 🚀 Getting Started

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Locally**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```
